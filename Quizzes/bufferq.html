What is saved on the stack during a function call?
- Return address (EIP)
- Old EBP value
- Function arguments
- Local variables
Why is EIP critical in buffer overflow attacks?
Overwriting EIP allows an attacker to redirect execution to attacker-controlled code.
What happens if a stack canary is modified?
The program immediately terminates to prevent exploitation.
How does stack canary affect variable layout?
Compiler rearranges variables by type instead of declaration order.
Why is gets() dangerous?
gets() does not check input length, allowing data to overwrite adjacent memory.
Where can buffer overflows occur?
- Stack
- Heap
- Data segment
What is a signed vs unsigned security risk?
Negative signed values may convert to large unsigned values, bypassing bounds checks.
Why can buffer overflow change program logic?
Overwritten memory may include control data, variables, or return addresses.
