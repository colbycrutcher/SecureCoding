CYBR 437 – Local Buffer Overflow Exploits

What is a buffer overflow?
When a program writes more data to a buffer than it was allocated, overwriting adjacent memory.
Why are buffer overflows dangerous?
They can overwrite control data (like return addresses) and allow attackers to execute arbitrary code.
What is privilege escalation?
When an attacker gains higher privileges (e.g., root) than they were originally allowed.
What are SUID and SGID?
Mechanisms that allow a program to run with the privileges of its file owner or group.
Why are SUID programs high-risk?
If vulnerable, a buffer overflow can grant attackers elevated (often root) privileges.
Main goal of a stack overflow exploit?
Control the instruction pointer (EIP/RIP) to execute attacker-controlled code.
Three main components of an exploit
NOP sled, shellcode, and a return address.
What is a NOP sled?
A sequence of NOP instructions that slide execution into the shellcode.
Why use a NOP sled?
It increases exploit reliability when the exact shellcode address is unknown.
NOP opcode on x86
0x90
What is shellcode?
Machine code used to perform the attacker’s desired action.
Early purpose of shellcode
Spawn a command shell for the attacker.
Modern shellcode can…
Escalate privileges, run commands, download malware, etc.
Shellcode representation
A sequence of architecture-specific binary opcodes, often shown in hex.
What does strcpy() risk?
It does not check bounds, making it vulnerable to buffer overflows.
Two categories of defenses
Compile-time defenses and run-time defenses.
Compile-time defenses are handled by…
The compiler.
Example of compile-time defense
Stack canaries (StackGuard).
What is a stack canary?
A value placed on the stack that is checked before function return to detect corruption.
Run-time defenses are handled by…
The operating system and processor.
NX bit purpose
Marks memory pages as non-executable to block injected code execution.
What is ASLR?
Randomizes memory addresses to make exploits unreliable.
What are guard pages?
Invalid memory gaps that crash a program if accessed.
